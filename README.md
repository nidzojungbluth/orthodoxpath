# OrthodoxPath

Kostenlose zweisprachige orthodoxe Lernakademie (Deutsch / Српски / Srpski) als installierbare Web-App (PWA).

**App öffnen:** https://nidzojungbluth.github.io/orthodoxpath/

Auf dem iPhone: Link in Safari öffnen → Teilen-Symbol → „Zum Home-Bildschirm“. Danach funktioniert die App auch offline.

- Keine Registrierung, keine Werbung, keine Abos
- Alle Daten (Fortschritt, Notizen) bleiben auf dem Gerät
- Die App ersetzt keinen Priester und ist keine kirchliche Autorität
